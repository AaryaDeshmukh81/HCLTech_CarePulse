# CarePulse – Telemedicine & Remote Patient Monitoring

CarePulse is a web-based healthcare platform developed as part of an **HCLTech project**. It aims to improve healthcare accessibility through digital patient management, doctor discovery, and remote patient monitoring.

## Features

- Patient profile management
- Doctor directory with multiple specializations
- Telemedicine support
- Remote patient monitoring
- Support request management
- Responsive user interface

## Technologies Used

- Angular
- TypeScript
- HTML5
- CSS3
- RxJS

## Installation and Setup

**Prerequisites:** Node.js and npm.

```bash
git clone https://github.com/AaryaDeshmukh81/HCLTech_CarePulse.git
cd HCLTech_CarePulse
npm install
ng serve --open
```
